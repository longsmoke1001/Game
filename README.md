# Ball Jump – 3D Platform Game

A 3D platform game where the player controls a ball to reach the goal. Built with Unity (C#).

## Features
- **8-direction movement** using WASD keys  
- **Shift boost** – hold Shift to jump further  
- Interactive mechanics: moving platforms, disappearing platforms, trigger-based unlock systems  
- Multi-level system with level switching and win conditions  
- Singleton pattern for game manager to handle game state and scene flow

## How to Play
- **WASD** – move the ball in 8 directions  
- **Shift** – hold while jumping to increase jump distance  
- Reach the red goal to complete the level

## Tools
- Unity 2022.3
- C#
- Visual Studio
